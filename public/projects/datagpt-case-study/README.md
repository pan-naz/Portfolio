# DataGPT screenshot placeholders

Source: `case studies/Datagpt/DataGPT — case study final.pdf` in the project root.

Images are extracted from the supplied PDF; research, prototype, design-system and competitor montages are rendered crops. Original media will replace these screenshots later.

Asset paths, dimensions and alternative text are defined in `src/data/datagpt-case-study.ts`. `before` deliberately reuses `navigator.webp` as a temporary image, as requested by the user. Replace its manifest entry when the final Before image arrives. `after` uses `context-after.webp`.
